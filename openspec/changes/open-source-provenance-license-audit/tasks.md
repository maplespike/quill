New reproducible tool `scripts/compare-provenance.py` normalises both trees (comments and string literals removed, Python keywords removed so a `.py` file cannot match a `.ts` file on shared keywords) and reports shared token 5-grams plus the longest common contiguous token run. **Result: 14 file pairs share any 5-gram; longest run 8 tokens; highest coverage of any predecessor file 0.44% — at or below Quill's own intra-repo noise floor (median 0.0000, max 0.3684 over 120 same-repo pairs).** The longest runs are a pandas idiom, a NumPy limit phrase, and the public portal name `the government of canada open data portal`; none is code. The LCS routine was unit-tested first and the first implementation failed 3 of 5 cases, so the reported figures come from the corrected version. `CREDITS.md` and `docs/open-source-audit.md` updated with the measurement, the reproduction command, and the limitations that remain: one predecessor revision rather than full history (clone is `--depth=50`), and token fingerprinting would not register a semantic reimplementation. "No substantial literal copying at this revision, by this method" is recorded as the supportable claim — "no code copied" is explicitly not asserted.
