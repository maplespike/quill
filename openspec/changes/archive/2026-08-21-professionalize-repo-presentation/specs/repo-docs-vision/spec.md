## ADDED Requirements

### Requirement: Vision document

The repository SHALL include a `docs/VISION.md` file describing the project's architecture, roadmap, and principles.

#### Scenario: Vision document exists

- **WHEN** a reader opens `docs/VISION.md`
- **THEN** the file SHALL contain the project's architecture overview, a roadmap summary, and the core principles

#### Scenario: Attribution recorded in Vision document

- **WHEN** the vision document records ideas produced with research-agent assistance
- **THEN** it SHALL include attribution and a license table for those contributions
