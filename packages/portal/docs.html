[00] Quickstart LIVE

One API key.
Every Canadian government source. Every response cited.

// 30-second quickstart

$ npm install @maplespike/sdk

// Initialize and query
import { MapleSpike } from '@maplespike/sdk'
const ms = new MapleSpike({ apiKey: 'ms_live_...' })

const result = await ms
  .agent('committees')
  .action('search', { query: 'housing' })

console.log(result.data)     // structured data
console.log(result.quality)  // freshness, confidence
console.log(result.citation) // source_url, license, hash
No key? Use mock mode. Pass _mock=true on any API endpoint to get sample data. Free on every plan, no upstream calls.

Or with curl:

$ curl https://api.maplespike.ca/v1/gov/search \
  -H "X-API-Key: ms_live_..." \
  -d '{"query":"housing","_limit":3}'

}
[01] Pipeline

How data flows

Each of the 28 data modules follows the same 4-stage pipeline:

  1. Ingestion — Dedicated fetcher downloads from each source (XML, CSV, RSS, JSON, HTML)
  2. Parsing — Raw data is cleaned and structured into typed records with consistent fields
  3. Verification — Every record gets a SHA-256 content hash for independent citation verification
  4. Cross-referencing — Entity resolution links people and organizations across all sources, detecting patterns that become signals

CLI: pnpm --filter @maplespike/engine sweep --full — runs all modules.

[03] MCP Setup 18 TOOLS

Connect from any AI client

MapleSpike exposes 18 tools (15 data + 3 AI) through the Model Context Protocol. Add this to your MCP client config:

{
  "mcpServers": {
    "maplespike": {
      "command": "npx",
      "args": ["@maplespike/mcp-server"]
    }
  }
}

Works with Claude Desktop, ChatGPT, Cursor, Windsurf, Gemini, and any MCP-compatible client. See the AI Tools page for per-platform setup.

[04] Architecture

Open source, self-hosted

Everything runs on your own K3s cluster. No data leaves your infrastructure.

maplespike/
├── packages/
│ ├── pipeline-core/  # 28 ingestion modules + verification + audit
│ ├── engine/          # Entity resolution, graph, signals, briefs
│ ├── api-server/      # REST API with Katzilla-quality envelope
│ ├── mcp-server/      # 18 MCP tools for AI agents
│ ├── sdk/              # TypeScript SDK (zero deps)
│ ├── sdk-python/        # Python SDK (zero deps)
│ ├── portal/            # This dashboard (static HTML)
