Documentation

Get started with the CivInt Canada API and MCP server in minutes.

Quickstart

1. Get your API key

Sign up for a free account and get your API key from the dashboard. Your key is a Bearer token that authenticates all requests.

$ export CIVINT_KEY="civint-xxxxxxxxxxxx"

2. Make your first API call

Query Canadian government datasets with a single curl command:

# Search for GDP data from Statistics Canada curl https://api.civint.ca/v1/gov/search \ -H "Authorization: Bearer $CIVINT_KEY" \ -G -d 'query=GDP&jurisdiction=federal&limit=3'

Response:

{ "tool": "query_gov_data", "query": "GDP", "results": [ { "source": "Statistics Canada", "title": "Gross domestic product, ...", "url": "https://www.statcan.gc.ca/..." } ], "totalCount": 1, "citation": { "hash": "sha256-abc123...", "license": "OGL-C", "verified": true } }

3. Set up MCP for AI agents

Add the CivInt Canada MCP server to your AI agent for natural-language queries against Canadian government data.

Claude Desktop

Add to your claude_desktop_config.json:

{ "mcpServers": { "civint-canada": { "command": "npx", "args": ["@civint/mcp-server"], "env": { "CIVINT_API_KEY": "your-key-here" } } } }

Claude Code (CLI)

claude mcp add civint-canada -- npx @civint/mcp-server \ --env CIVINT_API_KEY=your-key-here

Cursor

Add to your project's .cursor/mcp.json:

{ "mcpServers": { "civint-canada": { "command": "npx", "args": ["@civint/mcp-server"], "env": { "CIVINT_API_KEY": "your-key-here" } } } }

Windsurf

Add to .windsurf/mcp_config.json:

{ "mcpServers": { "civint-canada": { "command": "npx", "args": ["@civint/mcp-server"], "env": { "CIVINT_API_KEY": "your-key-here" } } } }

Continue (VS Code / JetBrains)

Add to .continue/config.json:

{ "experimental": { "mcpServers": { "civint-canada": { "command": "npx", "args": ["@civint/mcp-server"], "env": { "CIVINT_API_KEY": "your-key-here" } } } } }

Any MCP client

Or install globally and run as a subprocess:

# Install npm install -g @civint/mcp-server # Run CIVINT_API_KEY=your-key npx @civint/mcp-server

MCP Tools Reference

The MCP server exposes 6 tools for AI agents to query Canadian government data:

ToolDescriptionInput
query_gov_data Query StatCan, CKAN, provincial data portals, and federal spending records query (string), jurisdiction, category, limit
fact_check Check a claim against official government data with confidence scoring claim (string)
get_citation Retrieve and verify a SHA-256 citation hash hash (string)
latest_releases Latest government data releases and economic indicators jurisdiction, category, limit

Authentication

All requests (except /v1/health) require a Bearer token in the Authorization header:

Authorization: Bearer civint-xxxxxxxxxxxx

Response Envelope

Every response follows a consistent envelope with provenance metadata:

{ "data": { ... }, "meta": { "requestId": "civint-a1b2c3d4e5f6", "timestamp": "2026-05-12T04:00:00Z", "tier": "free", "callsUsed": 42, "callsLimit": 1000 }, "citation": { "hash": "sha256-abc...", "source": "Statistics Canada", "license": "OGL-C", "verified": true, "verifyCommand": "echo -n ... | sha256sum" } }

FAQ

What data sources are included?

Statistics Canada (WDS/SDMX), open.canada.ca (CKAN), LODE geospatial portal, provincial open data portals (Ontario, British Columbia, Alberta, Quebec), and federal spending and procurement data via BuildCanada integration. RSS/Atom feeds from government agencies are supported where available.

Is the API Canadian-hosted?

Yes. All infrastructure runs on Canadian sovereign infrastructure. No data leaves Canada for processing. Foreign cloud providers are never used unless explicitly opted-in for specific use cases.

What are provenance audit trails?

Every API response includes a SHA-256 content hash, source attribution, timestamp, and machine-readable license metadata. You can independently verify any data point using the hash. This gives you a complete, auditable chain from raw government source to delivered response — ready-made for transparency reporting, fact-checking, and regulatory documentation.

Can I self-host?

Enterprise tier includes self-hosted options. The core pipeline library is open-source (AGPL-3.0) so you can run the data processing layer yourself.

How is the data licensed?

All government data retains its original license (primarily OGL-C — Open Government Licence – Canada). Our AI curation and analysis layers are our own IP but we provide full attribution and citation chains so you can always verify at the source.
