2026-05-13
Multiple Auth Methods: Web3, Passkey, OAuth

MapleSpike now supports three new authentication methods alongside existing API keys. Sign in with your Ethereum wallet (SIWE/EIP-4361), a FIDO2 passkey (biometric or security key), or any OAuth 2.0 provider — all issuing the same JWT format for use with the API. Generic OAuth supports any OIDC provider via MAPLESPIKE_OAUTH_{NAME}_CLIENT_ID env vars, with GitHub built-in.

28 Canadian Government Data Modules

MapleSpike now ingests 28 data modules covering House of Commons and Senate committees, federal lobbying registry, procurement and contracts, Canada Gazette regulations, GIC appointments, Elections Canada third-party advertising, CanLII court decisions, LMIA data, provincial lobbying (Ontario), oversight bodies (OAG, PBO, Ethics, CB, CRTC), and newly added modules including SEDI insider trading, Bank of Canada rates, CIPO patents, CMHC housing, CRA charities, CRTC decisions, federal budget, Health Canada drug database, municipal data, NPRI emissions, proactive disclosure, provincial legislatures, and Species at Risk.
