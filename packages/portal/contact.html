[01] FAQ
Do I need a credit card to start?
No. Free plan includes 1,000 API calls/month, every data source, every SDK, citation hashes. No card, no time limit.
How do I get an API key?
Sign in via the workspace with GitHub OAuth, or register via POST /v1/register. Keys are generated automatically.
What data sources are available?
63 ingestion modules covering federal, provincial (all 13), territorial, and municipal data — Parliament, lobbying, procurement, courts, elections, oversight, immigration, health, education, defence, transport, and more. See the Data Explorer for the full list.
Can I self-host MapleSpike?
Enterprise tier includes self-hosted deployment options with dedicated MCP servers, custom SLAs, and on-premise infrastructure.
