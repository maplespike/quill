Docs for Agents

⬡ STOP! If you are an AI agent, LLM, or automated tool, read this page first. It explains how to consume CivInt Canada documentation optimally.

AI agents — whether coding assistants, chat bots, or automated tools — can query Canadian government data, search articles, fact-check claims, and analyze bias through CivInt Canada. This guide explains the available formats, endpoints, and best practices for agent consumption.

Available Formats

AI tools work better with Markdown than HTML. Every documentation page is available as clean Markdown using any of these methods:

1. Full Documentation Index

Discover all available documentation pages:

GET /llms.txt

Or load everything in a single file for large-context models:

GET /llms-full.txt

2. Per-Page Markdown

Append /index.md to any page URL to get raw Markdown:

# Example: https://civint.ca/docs.md # Or for any page: curl https://civint.ca/docs.md --header "Accept: text/markdown"

3. Content Negotiation

Request any page with the Accept: text/markdown header to receive Markdown instead of HTML:

curl https://civint.ca/docs -H "Accept: text/markdown"

The response includes an x-markdown-tokens header with an estimated token count for context window planning.

API Specification

The full OpenAPI specification is available for AI coding tools and code generators:

GET /v1/openapi.json

When added to an agent's context, it can generate correct API calls to any CivInt endpoint without manual documentation lookup.

MCP Server

The CivInt Canada MCP server exposes 4 tools for interactive queries. Connect it to any MCP-compatible agent:

ToolDescription
query_gov_dataQuery StatCan, CKAN, provincial portals
fact_checkCheck claims against official data
get_citationVerify SHA-256 citation hash
latest_releasesLatest government data releases

MCP Setup per Agent

Claude Desktop

Add to claude_desktop_config.json:

{ "mcpServers": { "civint-canada": { "command": "npx", "args": ["@civint/mcp-server"], "env": { "CIVINT_API_KEY": "your-key" } } } }

Claude Code (CLI)

claude mcp add civint-canada -- npx @civint/mcp-server \ --env CIVINT_API_KEY=your-key

Cursor

Add to .cursor/mcp.json:

{ "mcpServers": { "civint-canada": { "command": "npx", "args": ["@civint/mcp-server"], "env": { "CIVINT_API_KEY": "your-key" } } } }

Windsurf

Add to .windsurf/mcp_config.json:

{ "mcpServers": { "civint-canada": { "command": "npx", "args": ["@civint/mcp-server"], "env": { "CIVINT_API_KEY": "your-key" } } } }

Continue (VS Code / JetBrains)

Add to .continue/config.json:

{ "experimental": { "mcpServers": { "civint-canada": { "command": "npx", "args": ["@civint/mcp-server"], "env": { "CIVINT_API_KEY": "your-key" } } } } }

Any MCP Client

npm install -g @civint/mcp-server CIVINT_API_KEY=your-key npx @civint/mcp-server

Best Practices for AI Agents

  1. Start with /llms.txt — Discover what documentation pages exist before diving deep.
  2. Use /llms-full.txt for large-context models — Load all documentation in a single pass.
  3. Prefer Markdown over HTML — Use Accept: text/markdown to save tokens and improve accuracy.
  4. Use the MCP server for interactive queries — It handles data retrieval, verification, and citation automatically.
  5. Use the REST API for programmatic access — OpenAPI spec at /v1/openapi.json enables code generation.
  6. Check x-markdown-tokens headers — Plan your context window usage efficiently.
