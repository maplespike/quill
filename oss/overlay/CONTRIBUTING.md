# Contributing

Issues are welcome. Open an issue to report a defect or to ask a question.

Pull requests are not accepted yet. This repository is a public export. A maintainer ports a change back by hand. The project will say so here if that policy changes.

Do not open a pull request. Open an issue instead.

Report a vulnerability to `security@maplespike.ca`. Do not file a public issue for a vulnerability that is still exploitable. Read `SECURITY.md`.
