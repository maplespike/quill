# Quill Beta Testing Campaign

## Goal
Recruit 20-50 beta testers from Canadian researchers, journalists, developers, and
civic technologists to validate Quill's data quality, API usability, and MCP
integration before public launch.

## Target Audiences
1. **Academic researchers** — universities, think tanks, policy institutes.
2. **Journalists** — investigative reporters covering federal/provincial politics.
3. **AI agent developers** — building tools that need Canadian government data.
4. **Civic technologists** — open-data advocates, transparency organizations.
5. **Legal researchers** — CanLII, A2AJ, tribunal decisions.

## How to sign up
- Open a [Beta Tester issue](https://github.com/maplespike/quill/issues/new?template=beta-tester.md) on GitHub.
- Or email beta@maplespike.ca.

## What testers get
- Free API key (internal tier, 35,000 calls/day during beta).
- Direct access to maintainers for feedback.
- Listed in the contributors section (with permission).

## What we ask testers to do
1. **Use the API** — make real queries, report errors or unexpected data.
2. **Try the MCP tools** — connect via Claude Desktop or Cursor, test tool discovery.
3. **Verify citations** — reproduce a claim hash locally, report mismatches.
4. **Test the portal** — dark/light mode toggle, data explorer, onboarding flow.
5. **Report issues** — use the GitHub issue templates (bug_report, feature_request, docs-metadata-gap).

## Canada & open source
Quill is sovereign Canadian infrastructure. We're committed to open source and
transparent government data. Contributions welcome under AGPL-3.0.

## Campaign channels
- GitHub (issues, discussions, README badges)
- Academic mailing lists (university research groups)
- Journalism organizations (CAJ, local press clubs)
- AI/ML communities (Hugging Face, LangChain Discord)
- Open data communities (CKAN, OpenNorth, Code for Canada)
