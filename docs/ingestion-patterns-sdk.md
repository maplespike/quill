# Ingestion Patterns (SDK)

## Overview

This page documents ingestion patterns exposed by the Quill SDK surface.

## Patterns

### Pull ingestion

Scheduled pulls from upstream sources.

### Push ingestion

Webhook-driven ingestion.

### Batch ingestion

Bulk file/CSV ingestion.
